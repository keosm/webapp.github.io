# webapp.github.io

financial planning app
- uses planning feature from ynab api to keep track of user spending / give weekly and monthly spending advice. store info in db
- use gemini api to allow user to ask questions or ask for recommendations
- points feature where user is rewarded for saving money / spending responsibly
- extra money + a bonus is the amt of points added to account by the end of the week. points can be used in in-app store to redeem things
